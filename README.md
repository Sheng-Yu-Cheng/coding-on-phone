# coding-on-phone

在 iPhone 上刷 CSES／Codeforces／LeetCode 的網頁應用程式。程式在你自己的 Linux 電腦上編譯執行，手機端是一個不會叫出 iOS 鍵盤的編輯器，搭配專為寫程式設計的自製鍵盤。

- 後端只用 Python 標準函式庫，前端是原生 JavaScript，**沒有任何相依套件，也沒有建置步驟**。
- 支援 C++、C、Python。
- 語意補全與即時錯誤標示來自 `clangd`（C/C++）與 pyright／pylsp（Python）；沒裝就退回內建字詞補全。

## 安裝（Linux）

```bash
git clone https://github.com/Sheng-Yu-Cheng/coding-on-phone
cd coding-on-phone
./install.sh --apt     # 檢查 g++/gcc/clangd，註冊開機自動啟動的服務
```

腳本最後會印出用 Tailscale 讓 iPhone 連進來的五個步驟。更新版本：

```bash
git pull && systemctl --user restart coding-on-phone
```

前端改動只要 `git pull` 後在手機上重新整理即可。

## 安全性

這個服務會**編譯並執行收到的任何程式碼**，權限等同執行它的使用者。它預設只聽 `127.0.0.1`，請只透過 `tailscale serve` 這類私有網路對外，不要直接開到公開網路上。執行有時間、記憶體與輸出大小上限，但沒有檔案系統沙盒。

## 使用

1. 按 ☰，貼上題目網址（或直接打 CSES 題號，例如 `1068`）→ 抓取題目。
2. 「程式」頁寫解法，▶ 執行全部範例測資並比對。
3. 通過後按「複製」，到「題目」頁點「開啟原題／提交」貼上。

### 鍵盤

| 操作 | 效果 |
| --- | --- |
| 按鍵往上滑 | 輸入右上角的符號（等同 Shift＋該鍵） |
| ⇧ 點一下／點兩下／按住 | 單次／鎖定／像實體鍵盤一樣按住搭配其他鍵 |
| 按住空白鍵滑動 | 觸控板式移動游標；⇧ 開著時變成選取 |
| ⇧＋方向鍵 | 選取 |
| ← → 往上滑 | 行首／行尾；↑ ↓ 往上滑是檔頭／檔尾 |
| Tab | 展開片段或接受第一個補全建議，否則縮排 |
| 擴選／縮選 | 字 → 括號內 → 含括號 → 整行 → 區塊 → 函式，逐層放大或退回 |

`Ctrl` 組合：Z 復原、Y 重做、A 全選、C／X／V 複製剪下貼上、D 複製行、K 刪行、L 選行、/ 註解、W 擴選、←→ 以字移動、↑↓ 搬移整行、⏎ 執行、⌫ 刪除一個字。

### 檢視

- 在程式碼上滑動捲動時鍵盤會自動收起，點一下程式碼再彈出。
- 雙指縮放調整字體大小。
- 點兩下選字，點三下選行，⇧ 開著時點一下是延伸選取。

### 片段與模板

☰ → 片段與模板。打縮寫按 Tab 展開，`$0` 是展開後游標的位置；也可以先選取一段程式碼再「用選取的程式碼建立」。勾選「模板」的片段會在開新題時自動帶入。

## 題目來源

| 來源 | 狀態 |
| --- | --- |
| CSES | 主要支援：題敘、時限、範例測資 |
| Codeforces | 盡力而為；Cloudflare 常擋自動抓取，被擋時請用草稿加手動貼測資 |
| LeetCode | 盡力而為；只抓題敘與起始程式碼（函式題，本機測試要自己寫 `main`） |

## 資料

全部存在 `data/`（不進版本控制）：`data/problems/<題目>/main.cpp`、`problem.json`、`history/`（每次執行留一份，最多 40 份），以及 `data/snippets.json`。

## 設定

環境變數：`COP_PORT`（預設 8377）、`COP_HOST`（預設 127.0.0.1）、`COP_DATA`（資料目錄）。編譯參數在 `server/runner.py` 的 `COMPILE`，clangd 用的參數在 `data/problems/.clangd`。
